# Make a new box with zk init

## Goal

Starting a box today means copying the demo vault's files by hand. `zk init` should make them.

Done when:

- [ ] `zk init [folder]` writes `zk.toml` (name, folders, and an empty `[fields]` with the mappable fields listed in a comment), `<Name> Hub.md` and `<Name> Base.base`, and the cards and sources folders, refusing to overwrite anything.
- [ ] It refuses a folder that is not inside an Obsidian vault, saying why.
- [ ] `zk check` is clean on the new, empty box, and the demo vault's hub and base match what `zk init` writes.

## Next

Design the files zk init writes from the demo vault's, then build it with tests. Set the new box's property types with `box.AddTypes(vault, spec.Mapping.PropertyTypes())` (ADR 261115-2a31), or `zk check` warns on the new box.
