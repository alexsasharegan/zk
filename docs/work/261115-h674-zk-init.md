# Make a new box with zk init

## Goal

Starting a box today means copying the demo vault's files by hand. `zk init` should make them.

Done when:

- [x] `zk init [folder]` writes `zk.toml` (name, folders, and an empty `[fields]` with the mappable fields listed in a comment), `<Name> Hub.md` and `<Name> Base.base`, and the cards and sources folders, refusing to overwrite anything.
- [x] It refuses a folder that is not inside an Obsidian vault, saying why.
- [x] `zk check` is clean on the new, empty box, and the demo vault's hub and base match what `zk init` writes.

## Next

The maintainer reviews ADR 261115-j835 (proposed) and tries `zk init` on a scratch folder of a vault; then accept the ADR and close the item.
