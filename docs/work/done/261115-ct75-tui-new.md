# Build the zk new terminal UI

## Goal

Done when:

- [x] `zk new` on a terminal with missing arguments opens the UI; the header shows the box and why it was chosen.
- [x] The kind list scrolls and shows each kind's description from the box spec.
- [x] After the title and an optional parent (chosen by search), the card is made and opened in `$EDITOR` or Obsidian.
